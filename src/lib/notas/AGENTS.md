# Notes module rules
- Keep mock-issuer state in `nf_notas` (sent time, number, key), because server workers are stateless.
- Build monthly exports from `carregarMes` in `src/lib/notas/historico.server.ts` with aggregation pure in `historico.ts`; the month ZIP is zipped in the browser from signed URLs, so history screens and every export always agree on the same totals.
- Demo history is generated by `prepararDemonstracao` from the deterministic planner in `src/lib/notas/demo.ts`, skipping days that already exist, and inserts mock notes directly (bypassing `nf_criar_lote`) without files; `garantirArquivos` creates PDF/XML on first access, so preparing stays fast and re-running never duplicates.
- Keep the go-live checklist rules pure in `src/lib/notas/producao.ts` and recompute them server-side inside `ativarProducao`, so production can never be enabled from a stale screen.
